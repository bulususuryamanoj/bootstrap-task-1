🚀 Project Overview

This is a 3-page responsive portfolio website built using HTML5, CSS3, and Bootstrap 5.

📄 Pages Included

Home Page (index.html)
Introduction section, hero banner, and skills displayed using Bootstrap cards.

About Page (about.html)
Personal introduction and project description using a responsive two-column layout.

Contact Page (contact.html)
A clean, centered contact form built using Bootstrap form components and utilities.

🧩 Bootstrap Components Used

During this project, I explored Bootstrap’s official documentation and examples. I selected and remixed the following components:

Responsive Navbar

Hero / Jumbotron-style section

Cards for skills/features

Grid system for layout structure

Forms for the contact page

Buttons & utility classes for spacing and alignment

I focused on combining these components into a consistent and visually balanced layout rather than copying a full template.

🎨 Design Approach

Used Bootstrap’s spacing utilities (mt-, mb-, p-, g-) for clean layout structure

Maintained consistent alignment and section spacing

Ensured responsiveness across desktop, tablet, and mobile screens

Kept the design minimal and professional to match a personal portfolio style

🛠️ Tools & Resources Used

To complete this task, I used:

📘 Bootstrap 5 Official Documentation – For components and layout understanding

🤖 ChatGPT – For guidance on structuring pages, understanding Bootstrap usage, and speeding up development

💻 VS Code – For writing and editing code

🌍 GitHub – For version control and hosting

I did not copy any full Bootstrap example page. Instead, I extracted individual components and combined them creatively.

⚙️ Challenges Faced

One of the main challenges was:

Structuring multiple Bootstrap components together while maintaining visual balance

Ensuring proper spacing and responsiveness in a short amount of time

I solved this by:

Relying on Bootstrap’s grid system

Using utility classes for spacing and alignment instead of writing custom CSS

📚 Learning Outcome

Through this project, I learned:

How to effectively use Bootstrap’s grid and utility system

How to remix multiple UI components into a single cohesive design

The importance of responsiveness and layout composition

How documentation and AI tools can speed up development when used properly
